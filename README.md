# 📱 HenshinPhone

**HenshinPhone** is an experimental Android app that simulates Kamen Rider-style transformation devices.

Built with **Jetpack Compose**, it focuses on cinematic interaction, custom transformation logic, and extensibility.

---

## ✨ Features

- 🧭 Device selector (Faiz supported)
- 🔢 Custom 3-digit transformation codes
- 🎞 Custom transformation video playback
- 🖼 Custom finish image display
- 🔊 Sound effect toggle
- 🖤 Fullscreen immersive UI

---

## 📦 Current Status

- Version: **v0.1.0**
- Platform: Android
- Storage: Local (SharedPreferences)
- Media: Local device files

---

## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Android Media APIs
- Material 3
